## Key Demo Points

1. **Data Consistency**: Same customer appears across all modules with matching information
2. **Telecom Context**: Service usage, device financing, billing components
3. **AI Recommendations**: Telecom-specific suggestions based on usage and service status
4. **End-to-End Journey**: From risk assessment to payment recovery
5. **Real-time Updates**: Show how actions in one module affect others

## Demo Script Tips

- Start with overview statistics on Dashboard
- Pick one customer and follow their complete journey
- Highlight telecom-specific features (usage patterns, device plans, service status)
- Show how AI recommendations are contextual to telecom industry
- Demonstrate integration between modules (case → PTP → payment plan)
- End with reporting and analytics showing overall portfolio health
